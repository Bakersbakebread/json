# json.seanthorne.co.uk

A JSON viewer that runs entirely in the browser: paste, open or drop a file, then validate, format, minify, sort keys and explore it as a searchable tree.

Vue 3 + VueUse + Tailwind 4. Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.

```sh
npm install
npm run dev      # local dev server
npm run build    # type-check and build to dist/
```
